# Additional Code for Control Studies

In the directory `plots/`,
* Run `wolexfigures_with_freq.R` to obtain `wolex_figures_with_frequencies.pdf` (predictive informtion using corpus frequencies for 4 WOLEX languages)
* Run `hierarchical_samples.R` to obtain `figures/hierarchical_samples.pdf` (70 sampled combinations of coupling parameters in synthetic PCFGs)
* Run `plotPCFGJointResults.R` to obtain `figures/plotPCFGJointResults.pdf` (reorderings of 10 randomly generated PCFG sources at different inverse temperature parameters)
  
Plots were generated using `R version 4.4.2`.
